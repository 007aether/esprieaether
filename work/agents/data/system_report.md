## 1. ما هو النظام؟

نظام **ذكاء اصطناعي محلي كامل البناء** يعمل 100% على جهاز المستخدم (ولا يعتمد على السحابة لأغلب وظائفه)، ويتكون من:
- رأس تحكم (Head): Hermes + ECC + DSH + Sunna
- مُوجّه العقل (Brain Router): ai_router.py يربط 10 دماغ
- نظام وكالات (Agent OS): kernel + mesh + multi-brain
- 60 روبوت + 7 وكالات
- كرسل معرفي + ذاكرة + دورة تفرغ (cleanup)
- آلة تطور ذاتي (Autonome Evolve / Self-Heal)
- واجهات: البوت التليغرام + واجهة ويب + سحابة سطح المكتب + دار لينك

ملخص: "محمد على السطح...시스템을 كاملة على جهازك".

## 2. صورة المعمارية (Architecture)

```
Telegram / CLI / TUI
        ↓
      Hermes  (المشغّل الرئيسي)
        ↓
 ECC skills + hooks + memory vault   ← 311 مهارة قابلة لإعادة الاستخدام
        ↓
 EsprieAether Router  (ai_router.py)
        ↓
   3 دماغ:
   ① ollama-local  → qwen2.5:3b        (محلي، مجاني، لا حد لطلبات)
   ② llm7-fast     → mistral-Nemo      (سحابي مجاني بدون مفتاح)
   ③ llm7-big      → gpt-oss:20b       (سحابي مجاني أقوى)
        ↓
 60 روبوت + 7 وكالات + باكمان (Telegram bot, Cloud desktop, Sunna, Web UI)
```

## 3. المكونات الرئيسية

### 3.1 الرأس / Head
| المكوّن | الدرجة المتاحة | الدور |
|---|---|---|
| Hermes | مفعّل (default) | قفل الوجه الأمامي للدردشة والسيطرة |
| ECC | مفعّل (311 skill) | قالب سيرورات وتكرير العمل |
| DSH | مفعّل | واجهة سطح مكتب + وحدة تشغيل بدون رأس |
| Sunna | مفعّل (10 endpoints) | مساحة عمل الفريق والمتابعة والتقارير |

### 3.2 مُوجّه العقل (ai_router.py) — ONE mind, THREE brains
يتعامل مع كل طلب، ويختار الدماغ الأنسب ديناميكياً:
- **local**: qwen2.5:3b — سريع، مجاني، لا تقييد، لا مفتاح
- **fast**: mistral-Nemo-Instruct — بدون مفتاح، مجاني
- **big**: gpt-oss:20b — أقوى، بدون مفتاح، مجاني (يحمل 10 طلبات/دقيقة كحد)

والمزايا المدمجة فيه:
- صحافة صحافة الدماغات (health tracking + auto-recover بعد 60s)
- تقييد الطلب لكل دماغ
- توجيه ذكي: المطالبات فوق 8000 حرف → الدماغ الكبير أولاً
- stream (SSE) + غير stream
- نقطة /stats تظهر أي دماغ ساعد في أي طلب

### 3.3 نظام الوكالات (Agent OS)
- **Kernel (agent_kernel.py)**: يصادق ويتحقق من أفعال الوكالات قبل التنفيذ (سياسة تحكم صارمة لكل نوع من الأفعال: monitor/develop/repair/execute/manage)
- **Agent Mesh (agent_mesh.py)**: البلوع بين الوكالات والخدمات
- **Multi-brain Engine (multi_brain_engine.py)**: توزيعоложالذكاء بين الدماغات

### 3.4 البوتات والروبوتات
- 60 روبوت + 7 وكالات
- بوت التليغرام (Telegram bot + 3 نسخ/بيئات: bot1/bot2/robots)
- روبوتات متعددة: GitHub, email, market, airdrops, web3, knowledge, voice، وغيرها (مُوضحة في src/)

### 3.5 المعرفة والذاكرة
- **Knowledge Blueprint + Router**: لقراءة المعرفة والمعلومات
- **Obsidian Vault**: دليل معلوماتي للملاحظات والروابط
- **Memory Layer + Vector Memory**: تخزين وتشابه ذكريات المشروع والنصوص الويب وغيرها، قابل للاسترجاع والدعم
- **Knowledge Graph UI**: واجهة بصرية للمعرفة

### 3.6 التطور الذاتي / Self-Heal
- **Autonome Evolve (autonome_evolve.py)**: حلقة تطور ذاتي — تشخيص → قرار → إصلاح → تعلم → تقرير (−Daemon)
- **Self-Improve**: تحسين مستمر للنظام من نسخة لنسورة
- **Watchdog**: مراقبة طلاقة وقت التشغيل ورد الفعل
- **Auto-GitHub Learning / Autonomous Loop**: تعلم قياسي من بيئة التطوير

1. **الذاكرة النسبية**: 16.5GB — كافي لبعض النماذج القياسية، لكن نماذج 17GB فأكثر تطلب انتباه أو تجميع مسبق.

3. **السماح المحروم**: بعض الخدمات (Web Interface, Cloud Desktop) في إعداد أو في طور التجريب، وليس كل الخدمات متصلة 100%.
4. **الموديل المطلوب (27B)**: مشروع 17GB يستحيل تشغيله كنموذج مستقل بذاكرة 16.5GB بدون تجميع مسبق أو تنزيل مضاد؛ ويُلزم الأداء به.
