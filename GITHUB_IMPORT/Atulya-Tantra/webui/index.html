مؤشرات حالة النظام

نقاط التحكم السريع ولوحة الحالة كيعطو حالة الجهاز والنموذج فالوقت الحقيقي:

🟢 أخضر · شغّال / مباشر

🔵 أزرق · جاهز / متصل

الجهاز ولا التابع مربوط ومهيّأ وجاهز للأسئلة.

🟡 أصفر · كيستنى / كيبدا

الميزة مهيّأة ولكن كتستنى شرطاً (مثال: الإيماءات كتستنى الكاميرا) ولا كتحمّل أوزان النموذج.

🔴 أحمر · موقوف

الميزة موقولة ولا مقطوعة. اضغط على زر التحكم السريع باش تشغّلها.
