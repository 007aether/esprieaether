# دفعة إنتاج المخبزة

## الكميات التي ذكرها المستخدم
- 3 أفران، طول كل واحد 1.50 م.
- 3 عربات خبز.
- طاولة خبز واحدة.
- ذُكرت أيضاً معالف ومشارب للبهائم ضمن الأعمال الجارية.

## آخر حالة مسجلة
ذُكر شراء الصاج والحديد وإرسال صاج الأفران للثني، مع نية بدء تصنيع الأفران خلال الأسبوع. حدّث الحالة والتاريخ بعد كل تأكيد جديد.

## بيانات التكلفة المنتظرة
سعر وكمية كل مادة، سعر الثني، القطع والملحقات، ساعات العمل، المستهلكات، النقل، وأي ضرائب. لا تحسب سعر البيع قبل توفرها وتحديد الهامش.
