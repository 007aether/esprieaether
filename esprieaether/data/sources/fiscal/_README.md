# Sources pour l'agent L1 — Fiscalité

Déposez ici les barèmes et documents fiscaux **vérifiés** (TVA, IS, CNSS, déclarations).

- Seuls les fichiers ne commençant pas par `_`, `README` ou `.` sont lus comme source.
- `GET /agents/L1/run` renvoie `no_data_source` tant qu'aucun fichier n'est présent.
- Le contenu est renvoyé tel quel : aucune interprétation automatique.
